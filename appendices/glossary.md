# Glossary

## Agentic workflow

A workflow where a human directs AI agents toward clear outcomes, validates their work, and keeps the source of truth in shared project artifacts.

## Copilot CLI

GitHub Copilot in the terminal. In this exercise it supports planning, implementation, review, and validation loops.

## MCP

Model Context Protocol. MCP servers can expose external context, such as repository or project-management data, to compatible AI tools.

## Repository instructions

Durable guidance stored with the repository so Copilot can follow project conventions without repeated prompting.
