# Pricing and usage

Copilot usage depends on your GitHub plan and the models or features you use. Always check current public GitHub documentation for exact pricing and quota details.

Use these questions during the exercise:

- Did Copilot reduce time spent finding context?
- Did it increase or reduce review effort?
- Which tasks still required human judgment?
- Which model choice was good enough for the task?
- What guardrail stopped low-quality or unsafe output?

Sustainable adoption is not just lower typing time. It should improve flow, quality, knowledge sharing, or cycle time in a way the team can observe.
