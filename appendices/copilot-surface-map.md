# GitHub Copilot surface map

| Surface | Use it for |
|---|---|
| VS Code Copilot | In-editor chat, edits, explanations, and agent mode |
| GitHub Copilot CLI | Terminal-native planning, coding, review, and workflow automation |
| GitHub.com Copilot | Repository-aware questions, issue and pull request context |
| Copilot cloud agent | Background implementation from GitHub Issues |
| GitHub Actions | Repeatable validation and guardrails |
| GitHub Issues and Projects | Shared planning context for humans and agents |
| MCP servers | Additional context sources when the workflow needs them |
