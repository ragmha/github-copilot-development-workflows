# Contributing

Thanks for improving this exercise.

Before opening a pull request:

1. Keep examples GitHub-native and original.
2. Use TypeScript + Bun for runnable code.
3. Add or update behavior tests before changing behavior.
4. Run:

```bash
bun test
bun run lint
bun run validate
```

Do not add secrets, customer-specific content, or workflows that use `pull_request_target`.
