# Prompt: Review a Release Radar feature PR

```text
Review this Release Radar pull request against the issue acceptance criteria.

Focus on behavior:
- Are only merged PRs included?
- Are labels matched case-insensitively?
- Does the new section appear in the requested order?
- Do risky PRs keep their normal feature/fix/breaking-change section when applicable?
- Do tests describe observable behavior rather than implementation details?

Flag only issues that could make the release notes wrong, confusing, or hard to maintain.
```
